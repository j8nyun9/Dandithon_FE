# 단디보상운동 기획

## 한눈에
- **한 줄 소개**: 각자 형편대로 할 수 있는 만큼 내어놓았던 1907년 국채보상운동의 정신을 이어, 대학생의 시간·재능·헌혈을 학교 단위 공동 성취로 모으는 AI 기반 사회공헌 리그
- **슬로건**: 각자 할 수 있는 만큼, 우리 학교의 이름으로.
- **메인 헤드라인**: 1907년엔 반지를, 오늘은 시간을 내어놓습니다.
- **발표 첫 문장**
  > 1907년 대구, 누구는 돈을 내놓았고 누구는 끼고 있던 반지를 빼어 내놓았습니다. 저희는 그 질문을 오늘의 대학생에게 다시 던집니다. 지금 당신이 내어놓을 수 있는 것은 무엇입니까?

  짧은 버전: 1907년엔 반지를 내놓았습니다. 2026년의 대학생은 시간과 재능, 그리고 헌혈을 내어놓습니다.

## 핵심 서사
- 국채보상운동에서 가져오는 원리는 **"각자 형편대로, 할 수 있는 만큼 내어놓는다"** 이다. 1907년에 누구는 돈을, 누구는 반지를 냈다.
- 오늘의 대학생은 **시간(봉사) · 재능 · 헌혈**을 내어놓는다.
- 서비스의 중심은 **사회공헌**이다. 소비·지출 데이터는 다루지 않는다.

## 서비스 원칙
- 인증 가능한 사회공헌 활동만 집계한다. 자기 신고는 받지 않는다.
- 개인 랭킹은 없다. 비교는 학교 단위로만 한다.
- 많이 한 사람을 앞세우지 않는다. 한 시간도, 한 번의 헌혈도 같은 참여다.
- 한 학기에 한 번 참여해도 충분하다. 실패나 공백을 비난하는 문구를 쓰지 않는다.
- 헌혈은 권할 뿐 강요하지 않는다. 건강 상태에 따라 다른 방식으로 참여할 수 있다.
- AI는 DB에 등록된 활동만 추천한다. 수치는 서버가 계산하고 AI는 문장만 만든다.
- 시연용 데이터는 화면에 "시연용 데이터"로 표시한다.

## 참여 방식
### 내어놓는 것 (서사)
시간 · 재능 · 헌혈

### 사회공헌 유형 (측정, 6개)
| 유형 | 예시 활동 |
| --- | --- |
| 자원봉사 | 플로깅, 요양원 공연 |
| 교육·멘토링 | 지역아동센터 학습 멘토링 |
| 지역사회 기여 | 어르신 디지털 도우미 |
| 나눔 | 연탄 나눔 |
| 장학형 사회참여 | 장학재단 연계 멘토링 |
| 헌혈 | 교내 헌혈버스 |

- 한 유형으로 정하기 어려운 활동은 **두 유형에 ½씩** 반영한다. 예) 연탄 나눔 = 나눔 ½ + 자원봉사 ½
- 여러 차시로 이어지는 활동은 **한 번의 참여**로 인정한다.

## 인증
### 인증 등급
| 등급 | 방식 |
| --- | --- |
| 1365·VMS 연동 | 개인 동의 후 봉사 실적을 API로 자동 연동 |
| 운영자 확인 | 협력 기관 활동의 확인서·헌혈증을 운영자가 확인 |
| 공식 실적 확인 | 기관이 공식 실적으로 확인 |

- 1365·VMS에 없는 활동은 **등록된 협력 기관 활동**만 인증할 수 있다.
- 승인 상태는 승인 대기 / 승인 / 반려로 표시한다.

### 인증 확장 로드맵
1. **지금**: 1365 · VMS 연동 (개인 동의)
2. **확장**: 공개 API가 없는 기관은 협력 기관으로 등록할 때 실적 API 제공을 요청
3. **향후**: AI 인증 보조 (확인서 판독·이상 탐지, 최종 판단은 운영자)

AI 인증은 MVP에 구현하지 않고 제안서와 발표에서 다룬다.

## 시즌
- 시즌은 **한 학기(16주)** 다.
- **8주차 중간결산**, **16주차 최종결산**. 시상과 호외도 결산마다 한 번씩 나간다.
- 순위 변동은 "중간결산 대비"로 보여준다.

## 랭킹과 시상
- 순위는 학교별 **단디 지수**로 매긴다. 계산은 서버에서만 한다.
- 각 학교의 **6유형 육각형**(유형별 참여율 %)으로 참여 모양과 강점 유형을 보여준다. 리그 평균과 겹쳐 비교한다.
- 랭킹 화면에 "등록 시범 참가 집단의 참여 성과"임을 표시한다.
- **시상**
  - 단디 대상: 단디 지수 최고
  - 도약상: 중간결산 대비 순위 상승 최대
  - 유형별 부문상 6개: 자원봉사상, 멘토링상, 지역사회상, 나눔상, 장학참여상, 생명나눔상(헌혈)
- 공동 프로젝트: 대구·경북 겨울 헌혈 릴레이 (목표 횟수 대비 달성률)

## AI
- 사용자가 내어놓을 수 있는 것, 관심 유형, 가능한 시간을 고르면 등록된 활동 중에서 추천한다.
- 추천 카드에는 추천 이유, 난도, 반영 유형, 참여 신청 버튼이 있다.

## 파트너와 수익 모델
- **고객**: 사회공헌 캠페인을 운영하려는 기관·기업
- **제공하는 것**
  1. **캠페인 운영**: 리그 안에서 기관·기업 캠페인을 열고 대학생 참여를 모은다.
  2. **검증된 성과 리포트**: 인증 등급별 참여 인원·봉사 시간·헌혈 횟수, 공동 프로젝트 달성률, 승인·취소 이력 요약
  3. **참여 인사이트**: 활동 조회 → 지원 클릭 → 실제 참여 → 완료 퍼널을 익명 집계로 제공
     - 관심이 많은 활동
     - 진입장벽이 큰 활동 (클릭 대비 참여 전환이 낮음)
     - 도입 후 참여율이 오른 활동 (= 홍보가 부족했던 활동)
- 협력 기관이 새 활동을 기획할 때도 이 데이터를 쓰게 되어, 서비스에 의존하는 구조가 된다.
- 벤치마킹 후보: 기관·기업용 챌린지 서비스 "모터너스" (서비스 내용 확인 필요)

## 데이터와 개인정보
- 파트너에게는 학교·활동 단위 익명 집계만 제공한다. 개인 식별 정보, 개인별 이력, 증빙 파일은 제공하지 않는다.
- 증빙 파일(헌혈증 포함)은 운영자 확인용이며 공개 피드에 노출하지 않는다.
- 소비·지출 데이터는 수집하지 않는다.
