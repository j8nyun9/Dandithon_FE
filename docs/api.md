# API 약속

개발 주소: `/api`. 프론트엔드 개발 서버가 백엔드 3001번 포트로 전달합니다.

| 메서드 | 경로 | 용도 |
| --- | --- | --- |
| GET | /api/health | 서버 상태 |
| GET | /api/activities | 개발용 활동 목록 |

성공: `{ "data": ... }`

실패: `{ "error": { "code": "NOT_FOUND", "message": "요청한 API가 없습니다." } }`

활동 필드: `id`(문자열), `title`(문자열), `minutes`(숫자), `points`(숫자).

새 API는 이 문서에 요청·응답 예시를 먼저 합의하고 구현합니다. 인증·점수 지급·대학 리그·AI 추천·DB는 후속 구현 대상입니다. API 비밀 키는 프론트엔드에 넣지 않습니다.
